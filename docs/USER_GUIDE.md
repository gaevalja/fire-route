# FireRoute 시연 사용설명서

FireRoute에서 화재 진행에 따른 대피 안내를 확인하고, 다익스트라와 PPO가 같은 조건에서 어떤 경로를 선택하는지 재생할 수 있습니다. 건물 배치와 인원은 시연용 가정이며, 불·연기 수치는 0~100의 상대 위험 지표입니다.

## 1. 실행과 로그인

1. 시연 앱이 실행 중이면 [메인 시연 화면](http://127.0.0.1:3001/)을 엽니다.
2. 앱을 시작하려면 Docker에 연결된 터미널에서 `fire-route-git` 폴더로 이동해 아래 명령을 실행합니다. Windows에서 WSL로 Docker를 쓰는 경우 실제 시연 소스가 있는 WSL 폴더에서 실행합니다.

   ```bash
   make demo-scenario-up
   ```

3. 명령이 끝나면 시연 화면을 엽니다. **역할 / Role**을 고르고, 실행한 폴더의 `.runtime/access-codes.json`에서 해당 역할의 값을 확인해 **접속 코드 / Access code**에 입력합니다. 접속 코드는 시연 화면 공유나 녹화에 포함하지 않습니다.

| 역할 | 사용할 수 있는 기능 |
|---|---|
| **주민 / Resident** | 방을 선택해 현재 대피 안내를 확인하고 층별 건물 지도를 봅니다. |
| **구조대 / Responder** | 화재 진행을 제어하고, 가상 주민 이동·잔류 정보와 재생 기록을 확인합니다. 다익스트라·PPO 비교와 저장된 모델 검토도 사용할 수 있습니다. |

기본 언어는 한국어입니다. 화면 상단의 **언어 / Language**에서 **한국어** 또는 **English**를 선택합니다. 로그인, 실시간 상황판, 비교와 모델 검토에 같은 선택이 적용됩니다. 재생 도중 바꿔도 현재 장면을 유지하며, 새로고침과 로그아웃 후에도 브라우저가 선택을 기억합니다.

## 2. 다익스트라와 PPO 비교하기

1. **구조대 / Responder**로 로그인합니다.
2. 상단에서 **다익스트라 · PPO 비교 / Dijkstra vs PPO**를 열고 **보기 / Mode**를 기본값인 **동일 조건 비교 / Paired comparison**로 둡니다.
3. **테스트 풍속 / Test wind speed**, **시나리오 번호 / Scenario seed**, **최초 발화 방 / Initial ignition room**, **대피자 시작 방 / Starting room**을 지정합니다. 방을 **시드에 따라 무작위 / Random from seed**로 두면 동일한 시드로 같은 방을 다시 선택할 수 있습니다.
4. **비교 재생 만들기 / Generate comparison** 버튼을 누릅니다. **▶ 재생 / ▶ Play** 버튼이나 평면도 아래의 타임라인으로 원하는 장면을 봅니다.

두 정책은 같은 화재 프레임과 출발 방에서 시작해 같은 인지 지연, 이동 시간, 구조·사망 규칙을 따릅니다. 다익스트라는 불 지수 45 이상, 연기 지수 60 이상 또는 붕괴 구역을 제외해 출구 경로를 계산합니다. PPO는 `FIRE_EVAC_0015` 모델로 현재 위험을 보고 이동하거나 대기합니다. [비교 규칙 자세히 보기](EVACUATION_MODEL.md#single-resident-policy-comparison)

### 화면 읽기

| 화면 요소 | 확인할 내용 |
|---|---|
| **정책별 결과 / Policy outcomes** | 최종 결과와 종료 시각, 이동·대기 횟수를 나란히 표시합니다. 종료 시각은 발화 후 경과 시간입니다. 카드 아래의 현재 위치와 행동은 타임라인에 맞춰 바뀝니다. |
| **층별 평면도** | 파란색 **D**는 다익스트라, 초록색 **P**는 PPO입니다. 같은 구역에 있으면 두 표시가 함께 나옵니다. 층 탭을 누르거나 정책 카드의 위치 보기 버튼으로 해당 층을 엽니다. |
| **이동 경로 / Taken path** | 각 정책이 현재 재생 시각까지 지나온 구역을 순서대로 확인합니다. |
| **행동과 사건 / Actions and Events** | 두 정책의 이동·대기와 종료 사건을 공통 시간 기준으로 읽습니다. 한 정책이 먼저 종료돼도 다른 정책의 재생은 계속됩니다. |

**대피자가 있는 층 따라가기 / Follow the evacuee’s floor**를 켜고 **따라갈 대피자 / Track to follow**를 고르면 해당 정책이 층을 바꿀 때 지도가 따라갑니다. 같은 층을 계속 살펴보려면 따라가기를 끕니다.

### 재현 가능한 시연 예시

| 입력 | 값 |
|---|---|
| 시나리오 번호 | `2026` |
| 테스트 풍속 | `5 m/s` |
| 최초 발화 방 | `F1-R2` (1층 방 2) |
| 대피자 시작 방 | `F9-R3` (9층 방 3) |

이 입력의 검증 결과는 다익스트라 **11:01 사망**, PPO **10:00 출입구 구조**입니다. `03:00`에서 첫 행동을 확인하고 `10:00`으로 이동하면 PPO가 구조된 뒤에도 다익스트라의 재생이 이어지는 장면을 볼 수 있습니다. 화면의 결과는 선택한 시나리오 한 건을 설명합니다.

## 3. 실시간 상황판 보기

- **실시간 상황판 / Live Dashboard**에서 모의 시간, 고정 출발점의 계산 출구, 장치 ACK를 확인합니다. **내 위치(방) 선택 / Select your room**으로 다른 방의 안내를 조회할 수 있습니다.
- **화면 / View**에서 **3D 건물 / 3D building**, **2D 평면 / 2D floor plan**, **노드 모식도 / Node diagram**을 고릅니다. 층 목록이나 층 탭으로 이동합니다. 3D·2D 보기에서 구역을 클릭하면 해당 구역의 정보를 볼 수 있습니다.
- 구조대 화면에서 **+1초 / +1 s**, **+30초 / +30 s**로 모의 시간을 진행합니다. **자동 진행 / Run**과 **일시정지 / Pause**로 연속 진행을 제어합니다. **초기화 / Reset**은 새 시연 사건을 시작합니다.
- 구조대는 **보기 / Mode**를 **가상 주민 이동 / Simulated resident movement**으로 바꿔 개별 주민과 이동 상태를 확인할 수 있습니다. **대피 타임라인 / Evacuation Timeline**의 **▶ 기록 재생 / ▶ Play recording** 버튼을 누르면 현재 탭이 수집한 장면을 되돌려 볼 수 있습니다. 라이브 화면으로 돌아갈 때는 **● 실시간으로 / ● Return to live** 버튼을 누릅니다.
- 기본 설정에서는 일시정지 후 30초가 지나면 실시간 안내가 만료됩니다. **저장 기록 보기 / Saved snapshot**이 표시되면 인원과 위치는 화면에 적힌 저장 시각을 기준으로 읽습니다. ACK는 고정 출발점 안내에 대한 가상 장치의 응답 수입니다.
- 장치 응답이 빠진 상황을 시연하려면 **장치 C 중지 / Stop device C** 버튼을 누릅니다. 장치 C를 멈추고 모의 시간을 1초 진행합니다. **초기화 / Reset**으로 세 장치가 있는 새 사건을 시작할 수 있습니다.

## 4. 저장된 PPO 모델 검토하기

1. **다익스트라 · PPO 비교 / Dijkstra vs PPO**에서 **보기 / Mode**를 **저장 PPO 모델 검토 / Saved PPO model review**로 바꿉니다.
2. **학습 실행 / Training run**에서 모델을 고릅니다. 기본으로 제공되는 `FIRE_EVAC_0015`에는 학습 손실과 평가 기록이 포함돼 있습니다.
3. 풍속·시드·발화 방·시작 방을 정한 뒤 **선택한 모델로 재생 만들기 / Generate model replay** 버튼을 누릅니다. 현재 행동, 구역의 위험도, 행동 보상과 최종 결과를 확인합니다.
4. **손실 변화 / Training Loss**에서 전체 손실, 정책 손실, 가치 손실, 엔트로피를 전환합니다. 평가 기록이 있는 실행은 평가 성공률도 표시합니다.

다른 실험을 보려면 **runs 폴더 선택 / Select runs folder**로 `fire_evac/runs`를 엽니다. 모델과 함께 같은 실행 폴더의 학습 기록을 불러옵니다. **모델 파일만 선택 / Select model file only**에서는 개별 `browser_policy.json`으로 재생할 수 있습니다. `model.zip`만 있는 실행은 원본 `fire_evac` 환경에서 `python export_browser_policy.py --run FIRE_EVAC_XXXX`로 브라우저용 파일을 내보냅니다.

## 5. 문제 해결과 종료

| 증상 | 확인할 내용 |
|---|---|
| `Failed to fetch` 또는 접속 불가 | 시연을 시작한 `fire-route-git` 폴더에서 `docker compose --profile scenario-demo ps -a`로 `scenario-app`의 상태를 확인합니다. 종료됐다면 `make demo-scenario-logs`로 시작 오류를 확인합니다. |
| `No module named 'backend.model_replay'` | Docker가 빌드하는 폴더에 `backend/model_replay.py`와 `frontend/scenario/model-replay/`가 포함된 최신 시연 소스를 반영한 뒤 `make demo-scenario-up`으로 다시 빌드합니다. Windows와 WSL에 각각 저장소가 있으면 실제 명령을 실행한 폴더를 확인합니다. |
| 비교 메뉴가 보이지 않음 | 로그아웃 후 **구조대 / Responder** 역할과 해당 접속 코드로 다시 로그인합니다. |
| 비교 재생을 만들 수 없음 | 풍속은 `1`, `5`, `10`, `15 m/s` 중 하나를 선택합니다. 시나리오 번호는 `1`부터 `4,294,967,295`까지의 정수여야 합니다. |
| PPO 모델은 보이지만 손실 그래프가 비어 있음 | 학습 기록이 포함된 `runs` 폴더를 불러옵니다. 해당 실행 폴더에 `progress.csv`와 `eval_progress.csv`가 있으면 학습 손실과 평가 기록을 각각 읽을 수 있습니다. |

시연을 마치면 **로그아웃 / Sign out** 버튼을 누릅니다. 로컬 시연 서비스를 종료하려면 실행한 저장소에서 `make down`을 실행합니다.
