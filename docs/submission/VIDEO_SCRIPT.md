`make record-demo` starts the local HTTP demo and runs the real browser gate with Chrome screencast capture after login. It intentionally resets to a new incident and changes playback. Captured images, timestamped frames and optional demo-screen.mp4 are stored only under the printed ignored evidence path. FFmpeg with libx264 is optional for MP4 encoding; if absent, the result says FRAMES_ONLY_FFMPEG_UNAVAILABLE and retains frames plus capture.ffconcat. It is screen capture without narration, not a complete polished submission video. Screenshots are also retained for article/slide review.

To encode retained frames later, run FFmpeg from that run's recording directory using capture.ffconcat. Preserve recorded frame durations and aspect ratio.
